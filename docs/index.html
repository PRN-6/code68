Questions & Answers

Frequently Asked Questions

How does Code68 protect my private code and files? ↓

The cloud model never has direct access to your filesystem. All operations pass through explicit, sandboxed local Python tools. Code68 uses resolve_safe_path to prevent directory traversal attacks, masks API keys and secrets before logging, and blocks destructive commands like rm -rf.

Do I need an NVIDIA GPU on my local computer? ↓

No! That is the core architecture of Code68. The heavy neural network (Qwen2.5-Coder-7B) runs in the cloud (e.g. on Kaggle's free dual Tesla T4 GPUs or via OpenRouter/Groq), while your local machine only executes lightweight Python scripts and tools. You can run Code68 on an ordinary laptop.

Can I use Code68 on multiple projects? ↓

Yes! You configure your endpoint once using code68 setup (or code68 config --global), and then you can navigate into any directory on your computer (cd D:\projects\my-app) and type code68. It automatically binds to that project.

Can I run Code68 100% offline without the cloud? ↓

Yes! You can connect Code68 to your local Ollama instance (http://localhost:11434/v1). Run ollama run qwen2.5-coder:7b, and Code68 will execute 100% locally on your own hardware with no internet connection required.
